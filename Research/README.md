# Research — 자료조사

작품의 **사실 관계**를 확인한 기록을 모읍니다.
(원래 `Resrarch`로 철자가 틀려 있어 `Research`로 바로잡았습니다.)

- 시대 배경: 1940년대 프랑스, 나치 점령기
- 실존 인물·사건 조사
- 지명, 복식, 물가, 통행금지 같은 생활 고증
- 용어 확인

## 기록할 때 반드시 지킬 것

**출처를 같이 적으세요.** 출처 없는 메모는 나중에 "이게 사실이었나?"를 다시
확인해야 해서 두 번 일하게 됩니다.

```markdown
## 1942년 파리 통행금지

- 시각: (조사 필요)
- 출처: (링크)
- 확인일: 2026-09-12
- 확인함: Joseph
```

## 확신도 표시

| 표시 | 뜻 |
|---|---|
| ✅ | 출처로 확인된 사실 |
| ⚠️ | 들은 것 / 확인 필요 |
| ✍️ | 극적 효과를 위한 의도적 각색 |

**✍️ 표시는 특히 중요합니다.** 나중에 "이거 고증 틀렸는데?"라는 지적을 받았을 때,
몰라서 틀린 것인지 알면서 바꾼 것인지 구분할 수 있어야 합니다.
