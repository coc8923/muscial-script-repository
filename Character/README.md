# Character — 인물

등장인물 설정을 인물 한 명당 파일 하나로 정리합니다.

```
Character/
  ├─ marie.md
  ├─ antoine.md
  └─ ...
```

## 인물 파일 기본 틀

```markdown
# 마리 (Marie)

**나이**: 24세
**직업**: 서점 점원 / 레지스탕스 연락책
**음역**: 메조소프라노

## 한 줄 요약
겁이 많지만 물러서지 않는 사람.

## 욕망 (이 인물이 원하는 것)
동생을 살리는 것.

## 두려움 (이 인물이 피하려는 것)
자기 때문에 누군가 죽는 것.

## 말투
짧게 끊어 말한다. 감정이 올라올수록 더 짧아진다.

## 관계
- **앙투안**: 믿고 싶지만 믿지 못함
- **동생 뤼시앵**: 유일한 약점

## 주요 넘버
- 1막 4장 〈아직 어둡지 않아〉
```

> **왜 이렇게 나눠 쓰나요?**
> "욕망"과 "두려움"이 분명하지 않은 인물은 무대 위에서 움직이지 않습니다.
> 대사를 고칠 때마다 이 파일을 먼저 보면, 인물이 갑자기 딴사람이 되는 것을 막을 수 있습니다.
