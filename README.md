## ⚡ 매일의 작업 순서

```
작업 시작 전  →  Pull  (상대방 작업 받아오기)
작업 중       →  claude 실행해서 대본 쓰기
작업 끝난 후  →  Commit → Push  (내 작업 올리기)
```

> **"시작 전 Pull, 끝나면 Push"**
> 사고의 90%는 이 둘 중 하나를 빼먹어서 생깁니다.

---

## 👥 공동 작업 방식

두 사람이 각각 **자기 컴퓨터**와 **자기 Claude 계정**으로 작업하고,
GitHub를 가운데 둔 공동 창고로 씁니다.

```
   [맥]                                      [윈도우]
    │                                            │
    │      ┌───────────────────────────┐         │
    ├─────→│   GitHub (원본이 사는 곳)   │←────────┤
    │      └───────────────────────────┘         │
```

서로의 컴퓨터를 직접 연결하는 것이 아닙니다.
자세한 이유와 규칙은 [공동작업 규칙](docs/WORKFLOW.md)에 있습니다.
