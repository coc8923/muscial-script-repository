# Reference — 참고자료

작품을 만들며 **참고한 것들**을 모아두는 곳입니다.

- 참고한 다른 작품 (뮤지컬, 영화, 소설) 감상 메모
- 음악 레퍼런스 (곡 목록, 링크, 왜 참고하는지)
- 무대·의상·조명 이미지 메모
- 인터뷰, 기사 스크랩

## Research 폴더와 무엇이 다른가요?

| 폴더 | 담는 것 | 예시 |
|---|---|---|
| **Reference** | 창작에 영감을 주는 **예술적 참고** | "이 곡의 코드 진행을 참고" |
| **Research** | 사실 확인을 위한 **자료 조사** | "1942년 파리 통행금지 시각" |

## 파일 이름 규칙

영문 소문자 + 하이픈으로 씁니다. 예: `music-references.md`, `costume-notes.md`

## ⚠️ 저작권 주의

다른 사람의 가사·대본·악보를 **통째로 복사해 넣지 마세요.**
출처와 링크, 그리고 "무엇을 왜 참고하는지" 내 문장으로 적는 것까지만 합니다.
이 저장소는 공개(public) 상태일 수 있습니다.
