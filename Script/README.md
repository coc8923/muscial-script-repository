# Script — 대본

뮤지컬 《레지스탕스(RÉSISTANCE)》의 **대본 원본**이 사는 폴더입니다.

## 파일 나누는 방법

전체 대본을 **한 파일에 몰아넣지 마세요.** 장면(Scene) 하나당 파일 하나로 나눕니다.

```
Script/
  ├─ 01-prologue.md
  ├─ 02-paris-morning.md
  ├─ 03-first-meeting.md
  └─ ...
```

**왜 나누나요?**
두 사람이 같은 파일을 동시에 고치면 충돌(conflict)이 납니다. 대본은 코드와 달리
"어느 쪽 대사가 맞는지" 기계가 판단할 수 없어서, 충돌이 나면 사람이 한 줄씩
비교해야 합니다. 장면별로 나눠두면 "당신은 3장, 나는 7장" 식으로 영역을 나눌 수
있어서 충돌이 거의 나지 않습니다.

## 파일 이름 규칙

| 규칙 | 예시 |
|---|---|
| 두 자리 번호로 시작 | `01-`, `02-`, `03-` |
| 영문 소문자 + 하이픈(`-`) | `03-first-meeting.md` |
| 확장자는 `.md` | `.md` = 마크다운, 어디서든 열립니다 |
| 한글 제목은 **파일 안에** | 파일 첫 줄에 `# 3장 — 첫 만남` |

> **파일 이름을 왜 영문으로 쓰나요?**
> 맥과 윈도우는 한글 파일명을 내부적으로 다르게 저장합니다(맥은 NFD, 윈도우는 NFC).
> 요즘 git은 이걸 자동으로 맞춰주지만(`core.precomposeunicode` 기본값 true),
> 한번 어긋나면 되돌리기가 까다롭습니다. 파일명은 영문·숫자로, 한글은 파일 안에
> 쓰는 습관이 가장 안전합니다.
> 참고: [Git & Mac: Working with Unicode filenames](https://makandracards.com/makandra/17827-git-mac-working-unicode-filenames)

## 장면 파일 기본 틀

```markdown
# 3장 — 첫 만남

**장소**: 파리, 몽마르트르 뒷골목
**시간**: 1942년 10월, 새벽
**등장**: 마리, 앙투안

---

마리    (숨을 고르며) 여기서 기다리라고 했잖아요.

앙투안  기다렸어요. 세 시간을.

---

## 메모
- 앙투안의 첫 대사는 더 짧게 쳐낼 것 (2026-09-12, Joseph)
```
